## Usage

```tsx
import { MasonryGrid } from "@/components/ui/masonry-grid";

export default function DemoPage() {
  return (
    <MasonryGrid
      images={[
        "/gallery/image-1.jpg",
        "/gallery/image-2.jpg",
        "/gallery/image-3.jpg",
        "/gallery/image-4.jpg",
      ]}
    />
  );
}
```

If you do not pass `images`, MasonryGrid uses its built-in default Unsplash
images.
