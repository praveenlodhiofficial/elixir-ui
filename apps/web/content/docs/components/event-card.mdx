title: Event Card
description:
  Event Card is a clean UI component for displaying event details like image,
  date, title, and venue in a compact layout. It includes subtle motion effects
  and works well in grids or galleries.
---

### Animation Behavior

- **Vertical Translation** – The card smoothly moves upward (40px → 0px) as you
  scroll
- **Scale Effect** – The card grows from 90% to 100% scale for emphasis
- **Image Parallax** – The cover image zooms from 1.4x to 1x, creating depth
  separation
- **Rotation** – Subtle z-axis rotation for a polished entrance

## Usage

```tsx
import { EventCard } from "@/components/ui/event-card";

export default function EventGrid() {
  return (
    <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6">
      <EventCard
        name= "Event Title Goes Here",
        slug= "#",
        coverImage= "path/to/image.jpg",
        date= "Apr 20, 2026, 7:00 PM",
        venue= "Wood Castle Hotel, New Delhi",
        price= "₹ 1499 onwards",
      />
    </div>
  );
}
```

## Props

| Prop         | Type   | Default                        | Description                     |
| ------------ | ------ | ------------------------------ | ------------------------------- |
| `id`         | string | "1"                            | Unique identifier for the event |
| `name`       | string | "Sample Event Title Goes Here" | Event name/title                |
| `slug`       | string | "sample-event"                 | URL-friendly event identifier   |
| `coverImage` | string | "/demo.jpg"                    | Event cover image URL           |
| `date`       | string | "Mar 25, 2026, 7:00 PM"        | Event date and time             |
| `venue`      | string | "Venue to be announced"        | Event location                  |
| `price`      | string | "₹ 999 onwards"                | Ticket pricing                  |
