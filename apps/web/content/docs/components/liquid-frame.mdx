---
title: Liquid Frame
description:
  Liquid Frame is an interactive image component that creates fluid ripple
  effects in response to mouse movement, combining WebGL shaders with three.js
  for smooth wave propagation and distortion animations.

## Usage

```tsx
import { LiquidFrame } from "@workspace/ui/components/liquid-frame";

export function Demo() {
  return <LiquidFrame src="/path/to/image.png" alt="My Image" fit="cover" />;
}
```
