---
title: Quantity Stepper
description:
  A compact, animated quantity control that toggles between an ADD button and a
  stepper interface with increment and decrement actions. Built with smooth
  transitions using Motion Library. Designed as a reusable UI component for
  selecting item quantities in modern applications.
